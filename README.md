# healthcare-knowledge-agent
A grounded Copilot Studio agent that answers questions from synthetic healthcare operations policies.

Home health clinicians and support staff frequently need to find operational guidance while completing time-sensitive workflows. Relevant information may be distributed across policies, training guides and workflow documentation, making manual searching slow and inconsistent. This project will demonstrate a Microsoft Copilot Studio agent that retrieves information from a controlled set of synthetic healthcare operations documents and produces grounded answers with source references. The agent will be instructed to acknowledge when its knowledge sources do not contain the requested information and will not provide diagnoses, treatment recommendations or patient-specific clinical advice. Success will be measured through a documented test suite covering answer accuracy, correct source use, unsupported-question handling and adherence to safety boundaries.
